# RATTIB — GitHub Pages

A Framework for Learning Game Design Principles
Arrange to Understand

Pakej lengkap laman RATTIB: halaman utama, Section A–H (56 kad), RATTIB Challenge (Arrange, Guess the Card dan Connect), CSS, JavaScript dan semua gambar.
Tema warna dan kandungan mengikuti versi laman yang diterbitkan pada 20 Oktober 2026.

## Terbitkan melalui GitHub Pages

1. Ekstrak ZIP ini di komputer anda.
2. Cipta repository GitHub baharu, contohnya `rattib`. Untuk cara percuma yang paling mudah, gunakan repository Public. Kandungan dan kod dalam repository Public boleh dilihat oleh orang lain.
3. Di repository, pilih Add file → Upload files. Muat naik SEMUA kandungan hasil ekstrak, termasuk folder `assets` dengan keseluruhan isinya. Fail `index.html` mesti berada pada aras utama repository, bukannya dalam folder `dist` atau satu lagi folder RATTIB. Pastikan fail `.nojekyll` turut dimasukkan (ia mungkin tersembunyi pada komputer anda).
4. Commit fail ke branch `main`.
5. Buka Settings → Pages. Di Build and deployment, pilih Source: Deploy from a branch.
6. Pilih branch `main`, folder `/ (root)`, kemudian Save.
7. Tunggu proses penerbitan selesai. Buka alamat yang dipaparkan oleh GitHub Pages. Biasanya formatnya https://NAMA-PENGGUNA.github.io/rattib/ apabila nama repository ialah `rattib`.

Panduan rasmi: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Semakan selepas penerbitan

- Buka halaman utama dan semak gambar poster.
- Buka setiap Section A–H dan cuba menukar kad.
- Klik RATTIB Challenge dan cuba ketiga-tiga mod.
- Semak pautan Back to RATTIB.
- Cuba tulis dan muat turun satu refleksi.
- Semak paparan pada telefon.

## Fail penting

- index.html — halaman utama.
- challenge.html — ketiga-tiga mod aktiviti dalam satu fail HTML.
- section-a.html hingga section-h.html — halaman pembelajaran.
- section-*-data.js, section-*.js, section-*.css — kandungan, interaktiviti dan tema setiap section.
- assets/ — poster dan kesemua 56 imej kad.
- .nojekyll — melangkau pemprosesan Jekyll bagi fail statik.

Pautan dalaman menggunakan laluan relatif supaya laman boleh digunakan dalam subfolder repository GitHub Pages.
Tiada proses build atau pemasangan pakej diperlukan. Pautan sumber luar memerlukan sambungan Internet.

## Refleksi dan rekod latihan

Data disimpan dalam pelayar masing-masing melalui localStorage. Tiada pangkalan data pusat atau akaun pelajar dalam pakej ini. Rekod daripada domain ChatGPT Sites atau fail HTML tempatan tidak berpindah secara automatik ke domain GitHub Pages. Pengguna boleh memuat turun nota refleksi melalui butang yang tersedia.

Untuk kemas kini pada masa hadapan, gantikan fail yang berkaitan dan commit ke branch penerbitan. Salinan GitHub Pages dan ChatGPT Sites perlu dikemas kini secara berasingan.
